# KyaDekhun Landing Page

> **KNOW WHAT TO WATCH.**  
> The intelligent streaming & entertainment discovery app that helps movie lovers and casual viewers decide what to watch in seconds across Netflix, Prime Video, JioHotstar, Apple TV+, SonyLIV, and theatres.

![KyaDekhun Landing Page](public/kyadekhun_logo.png)

## 🌟 Key Features

- **Cinematic Dark Entertainment Aesthetic**: Custom charcoal and deep purple palette designed for modern streaming enthusiasts.
- **Hero Showcase with Real Mobile Screens**:
  - Vibe & Mood Tuning
  - Unified Discover Hub (In Theatres & New on OTT)
  - Proprietary KyaDekhun Score & Multi-Platform Aggregator
  - 1-Tap Direct Streaming
- **Interactive Mood & Vibe Discovery**: Live recommendations tailored to 7 distinct energies (*High-Adrenaline, Mind-Bending, Crime & Mystery, Dark & Unsettling, Feel-Good, Romance, Something Chill*).
- **Personalization Engine**: Split-screen comparison contrasting generic trending billboard feeds against taste-calibrated picks.
- **Direct Google Play Store Links**: Integrated download links to the official [KyaDekhun App on Google Play](https://play.google.com/store/apps/details?id=com.kyadekhun.app).
- **Techviora Attribution & Official Social Links**: Linked to official Instagram and LinkedIn channels.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm / pnpm / yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/pcpvin/kyadekhun-landing.git

# Navigate to project directory
cd kyadekhun-landing

# Install dependencies
npm install

# Start development server
npm run dev
```

### Building for Production
```bash
npm run build
```
